# FurniProp

A working **fictional DEMO** of a fully furnished property marketplace, built from [FURNIPROP_PRD_CODEX.md](FURNIPROP_PRD_CODEX.md). It includes a buyer discovery flow, an image variant package preview with server-calculated indicative pricing, and role-scoped developer/admin pages. It is not a live property portal.

## Run locally

Requires Node.js 20.9+ and Docker. PostgreSQL 17 runs in a local container and stores its data under ignored `.local/` files. No external provider credentials are needed for DEMO mode.

```bash
npm ci --no-audit --no-fund
bash scripts/setup-local.sh
npm run dev
```

Run these commands from the repository root. In GitHub Codespaces, open the **Ports** tab and select port **3000** after `npm run dev` starts. If the Codespace was created before this app was pushed, run `git pull origin main` first. Use the **Buyer demo**, **Developer demo**, or **Admin demo** buttons on the sign-in page. Those shortcuts work only when `DEMO_MODE=true` and Next.js is running in development mode. `.env.local` and the local database credential are generated by `scripts/setup-local.sh`, ignored by Git, and never printed. The setup script is safe to rerun: it starts the same PostgreSQL container, deploys pending migrations and inserts missing fictional seed records.

If port 5432 is occupied, stop the conflicting local service or adjust the port and generated `.env.local` before setup. Do not put real provider keys in `.env.local` for this demo.

## Checks

With PostgreSQL running and seeded:

```bash
npm run lint
npm run typecheck
npm test
npm run build
npm run test:e2e
```

The browser tests use system Chromium when `/usr/bin/chromium` is present. Otherwise install Playwright Chromium (`npx playwright install chromium`) or set `CHROMIUM_PATH` to a local Chromium executable. The browser suite starts its own development server when one is not already running.

## Architecture and boundaries

- Next.js App Router, TypeScript and Tailwind CSS, with PostgreSQL/Prisma migrations and a JavaScript Prisma client adapter.
- Hashed passwords, hashed persistent session tokens, HTTP-only cookies, and server-side role and organization checks. DEMO sign-in is unavailable in production. Production authentication still needs a verified identity provider, MFA for privileged roles and abuse controls.
- Published search uses a furnished unit plus an approved package to calculate the headline price. Prices use integer paise. The visualizer requests a fresh server quote when a package changes and swaps only to a mapped approved DEMO image.
- Demo images are original conceptual illustrations. Projects, addresses, prices, developers and availability are fictional. No RERA verification, licensed real inventory, physical zone, SMS/email, payment or Unreal streaming provider is connected.
- `DEMO_MODE=false` or a production server excludes seeded DEMO accounts and listings from public discovery. Live publishing needs a separate verified content and legal review workflow.
